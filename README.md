# Repo to contain the patches for [Lore angel - Pure Data Spectral Freezer + Glitch Drum Machine ][https://www.youtube.com/watch?v=51UgOlnMCB0&lc=UgyhtgkSlF_n_O7Bnm94AaABAg.AdP3vv80eK-AddBz9WKQGY]

The patch used in the video is pulsar2.pd. 
Feel free to look around in the other patches.
You need to select your own samples by pressing "read file" button on the sampler~.pd and "load" button on the idm_drums.pd.
idm_drums.pd expects your drum samples to be named 0.wav, 1.wav, 2.wav etc. You should select a folder that contains all these files when pressing the "load" button.

Important:
The patch for freezer~.pd is heavily adapted from Gabriel Lecup on https://forum.pdpatchrepo.info/topic/9373/freeze-patches/2, all rights to them.

Let me know if something does not work!
